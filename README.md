# fb-comment-exporter-chrome-extension

Экспорт фейсбук-поста вместе со всеми ветками комментариев в формате Markdown (`.md`) и быстрое открытие скрытой ленты репостов.

Компактное расширение для браузеров на базе Chromium (**Google Chrome, Brave, Arc, Microsoft Edge, Vivaldi, Яндекс.Браузер**), которое добавляет в окно публикации Facebook две аккуратные кнопки-иконки (`28×28px`) сразу справа от счётчика репостов:

```text
👍 397   💬 251   ↗ 103   [ ⬇ ]  [ ☍ ]                        👁 78 549
```

---

## ✨ Возможности

1. **`[ ⬇ ]` — Полный экспорт поста и всех веток комментариев в Markdown (`.md`):**
   - Автоматически переключает фильтр комментариев с *«Самые актуальные»* на **«Все комментарии»**.
   - Самостоятельно прокручивает модальное окно поста до самого конца (поддерживаются длинные дискуссии на **250+ комментариев**) и последовательно раскрывает все свёрнутые ветки (*«Посмотреть X ответов»*, *«Посмотреть еще комментарии»*, *«Ещё»*).
   - Показывает живой индикатор прогресса в правом нижнем углу экрана (`⏳ v2.4 · Раскрыто комментариев: 237...`) и итоговое число скачанных комментариев прямо на кнопке (`✓ 234`).
   - Сохраняет иерархию вложенности ответов (уровни 0, 1, 2+), имена авторов, таймстампы, реакции, прямую ссылку на пост и YAML-шапку (Frontmatter), готовую для **Obsidian / Notion / Logseq**.

2. **`[ ☍ ]` — Открытие скрытой ленты всех репостов публикации:**
   - Даже если у поста зашифрованная ссылка вида `pfbid023iG2...`, встроенный мост `bridge.js` автоматически декодирует внутренний Base64 `storyID` (`UzpfSTEwMDA...`) из React Fiber и извлекает настоящий числовой `post_id`.
   - По клику на кнопку с иконкой трёх узлов `[ ☍ ]` открывает страницу со всеми публичными репостами записи: `https://www.facebook.com/shares/view?id=<post_id>`.

3. **100% приватность и локальная работа:**
   - Расширение работает исключительно внутри открытой вкладки браузера, не использует внешние серверы, не требует ключей API и никуда не передаёт данные.

## 🚀 Установка из GitHub (за 1 минуту)

Так как расширение устанавливается напрямую из исходников в режиме разработчика, подписка Chrome Web Store не требуется:

### Шаг 1. Скачайте файлы репозитория
- **Вариант А (через архив):** нажмите зелёную кнопку **`<> Code`** в правом верхнем углу страницы репозитория [Petergluk/fb-comment-exporter-chrome-extension](https://github.com/Petergluk/fb-comment-exporter-chrome-extension) и выберите **`Download ZIP`**. Распакуйте скачанный архив в любую постоянную папку на компьютере (например, `Документы/fb-comment-exporter-chrome-extension`).
- **Вариант Б (через Git):**
  ```bash
  git clone https://github.com/Petergluk/fb-comment-exporter-chrome-extension.git
  ```

> ⚠️ **Важно:** не удаляйте распакованную папку после установки — браузер запускает расширение напрямую из неё.

### Шаг 2. Подключите папку в браузере
1. Откройте в адресной строке браузера страницу расширений:
   - Chrome: `chrome://extensions`
   - Brave: `brave://extensions`
   - Edge: `edge://extensions`
2. В правом верхнем углу включите переключатель **«Режим разработчика» (Developer mode)**.
3. В левом верхнем углу нажмите кнопку **«Загрузить распакованное расширение» (Load unpacked)**.
4. Выберите папку `fb-comment-exporter-chrome-extension` (ту, внутри которой лежит файл `manifest.json`).

### Шаг 3. Как пользоваться
1. Откройте [facebook.com](https://www.facebook.com) (если вкладка уже была открыта — обновите её через `F5` / `Cmd + R`).
2. Откройте любой пост с комментариями (нажав на кнопку комментариев под постом, чтобы открылось окно *«Публикация ...»*, либо перейдя по прямой ссылке на пост).
3. В строке счётчиков (`👍 💬 ↗`) появятся две кнопки:
   - Нажмите **`[ ⬇ ]`**, чтобы плагин сам раскрыл все ветки до конца и скачал готовый `.md`-файл.
   - Нажмите **`[ ☍ ]`**, чтобы открыть ленту всех репостов этого поста в новой вкладке.

## 🔄 Как обновить расширение до новой версии
Если вы скачали обновлённый архив или сделали `git pull`:
1. Распакуйте новые файлы **в ту же самую папку** `fb-comment-exporter-chrome-extension` с заменой старых файлов.
2. Откройте `chrome://extensions` и нажмите круглую стрелку **⟳ (Обновить)** на карточке расширения.
3. Перезагрузите открытую вкладку Facebook (`F5` / `Cmd + R`).

## ❓ Частые вопросы (FAQ)

**В счётчике поста написано 251 комментарий, а скачалось 234. Почему?**  
Счётчик Facebook под постом включает удалённые комментарии, комментарии от скрытых/заблокированных профилей, пустые стикеры без текста и комментарии, отфильтрованные антиспам-системой самого Facebook. Скрипт выгружает все 100% реально доступных текстовых комментариев.

**В консоли разработчика (F12) видна огромная красная надпись «Остановитесь!». Это ошибка плагина?**  
Нет! Это стандартное предупреждение безопасности самого сайта Facebook (`facebook.com/selfxss`), которое Facebook выводит в консоль браузера абсолютно каждому пользователю при загрузке любой страницы, чтобы защитить людей от мошенников, просящих вставить вредоносный код в консоль.

## 📁 Состав репозитория

- `manifest.json` — конфигурация расширения Chrome Manifest V3.
- `content.js` — основной скрипт: встраивание кнопок, автопереключение фильтра, прокрутка ленты, раскрытие всех вложенных веток и сборка иерархического Markdown.
- `bridge.js` — скрипт-мост (`world: "MAIN"`), извлекающий скрытый числовой `post_id` из React Fiber (`storyID: "Uzpf..."`) для открытия ленты репостов.
- `styles.css` — компактные стили кнопок (`28×28px`) и плавающего индикатора прогресса с поддержкой светлой и тёмной темы Facebook.
- `icon16.png`, `icon48.png`, `icon128.png` — иконки расширения.
